# remedf

Pesquisa simplificada de medicamentos no REME/DF em formato de PWA.

## Como executar localmente

No diretório do projeto, rode:

```bash
python3 -m http.server 8080
```

Depois acesse `http://localhost:8080`.

## Deploy no GitHub Pages

1. Faça push para o branch principal.
2. Em **Settings > Pages**, selecione o branch principal como origem.
3. A aplicação ficará disponível no domínio do GitHub Pages do repositório.
